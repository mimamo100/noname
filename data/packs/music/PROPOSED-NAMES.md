# Proposed name categories for the Music pack

These break the ordinary-words rule, so they are NOT in the pack. If the owner agrees, each
list can become a category file (e.g. `band.txt`, `artist.txt`, `composer.txt`) as written.
One-word names only, lowercase letters, typed as players would type them (no accents,
no "the"). Best known first.

Ambiguous or everyday-word names are marked with * and listed at the end of each section.
